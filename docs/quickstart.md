# Quickstart

This page is the shortest practical path through FlexSoC.

## Install

```bash
uv sync
source .venv/bin/activate
fx --help
```

## Core rule

The flow is split into source-of-truth stages:

```text
HJSON/registers  ->  reg/doc
RTL core         ->  top wrapper
filelists        ->  lint
Python model     ->  vector tests
SV/cocotb TB     ->  simulation
netlist/SDF      ->  STA/power
```

`setup_tb` and `setup_cocotb` create verification infrastructure only. The test
vectors are generated by the model with `tests_gen` or `test_gen`.

## Single-clock smoke flow

```bash
fx settings TOP=test RUN_TOP=test RUN_ID=dev HOST=uart CLOCK_MODE=single

fx setup --force
fx hjson --force
fx reg doc --force
fx rtl_stub --force
fx top_from_core --force

fx flist --force
fx lint

fx setup_model --force
fx tests_gen
fx tests

fx setup_tb --force
fx setup_cocotb --force

fx sim --set TEST_NAME=smoke
fx cocotb --set TEST_NAME=smoke
```

Run all generated tests:

```bash
fx sim_tests
fx cocotb_tests
```

Run signoff:

```bash
fx syn sdf sta power --force
```

fx settings TOP=tri_stream_dsp RUN_TOP=tri_stream_dsp RUN_ID=dev HOST=uart CLOCK_MODE=multi

Run all generated multi-clock tests:

```bash
fx sim_tests
fx cocotb_tests
```

Run signoff:

```bash
fx sdc_multi --force
fx syn sdf sta power --force
```

## Debug output

Default mode prints compact progress and log paths. Use `--live` when you want
the full tool output in the terminal:

```bash
fx sim_tests --live
fx cocotb_tests --live
fx syn sdf sta power --force --live
```

## Full E2E pytest

The full regression lives directly in `tests/test_e2e_fx.py` and is opt-in:

```bash
FLEXSOC_RUN_E2E=1 pytest -s tests/test_e2e_fx.py
```

Skip signoff during quick debugging:

```bash
FLEXSOC_RUN_E2E=1 FLEXSOC_E2E_SKIP_SIGNOFF=1 pytest -s tests/test_e2e_fx.py
```

Show live tool output:

```bash
FLEXSOC_RUN_E2E=1 FLEXSOC_E2E_LIVE=1 pytest -s tests/test_e2e_fx.py
```
