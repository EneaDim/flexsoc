FSM per interfaccia tipo AXI-Lite:
- IDLE attende una transazione
- Read: handshake indirizzo read -> prepara -> handshake dato read
- Write: handshake indirizzo write -> handshake dato write -> handshake risposta write
- Se slv_err durante una transazione vai in ERROR finché clear_error
busy=1 durante la transazione; valid=1 quando stai presentando dato/risposta.
