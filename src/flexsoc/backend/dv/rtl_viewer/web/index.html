Navigate the RTL schematic
Drag the canvas to pan, use the mouse wheel or toolbar for zoom, and double-click a module to enter. Click any routed wire to inspect its signal; hold Ctrl/Cmd while selecting to track through proven direct port bindings.
Inspector: use the single Inspector button to open the right panel. Select SystemVerilog, Lint, or Paths from its tabs. Right-click actions navigate to the same panel; no separate lint overlay is used.
Contextual actions: right-click a generated group to expand only that group, or right-click an individual member to collapse it.
Keyboard: Ctrl+K focuses the loaded hierarchy filter; arrow keys navigate its visible entries; / focuses schematic search. Inspector tabs support Left/Right/Home/End. The Neovim button starts an actual local Neovim process when the viewer runs with FLEXSOC_RTL_NEOVIM=1 fx rtl-view (or --enable-neovim in scripts/rtl_viewer.py); otherwise the read-only source view is available with limited Vim keys. Esc closes menus or clears selection.
