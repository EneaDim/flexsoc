# DSP_stream — medium-complexity RTL schematic acceptance design

Five synthesizable SystemVerilog modules: `DSP_stream`, `DSP_frontend`,
`DSP_fir`, `DSP_mul_lane`, `DSP_saturate`. The elaborated design has one top,
three pipeline blocks and **six replicated multiplier instances** (ten scopes).
The processing pipeline includes multiplication, a generated six-tap FIR
reduction, registers with reset and enable, and saturation.

## Real RTL → Slang AST → graph → localhost

From the FlexSoC repository root, with upstream **SystemVerilog slang** on PATH:

```bash
python scripts/rtl_viewer.py \
  --root examples/rtl_schematic_dsp_complex --top DSP_stream \
  --file DSP_stream.sv --file DSP_frontend.sv --file DSP_fir.sv \
  --file DSP_mul_lane.sv --file DSP_saturate.sv --check

python scripts/rtl_viewer.py \
  --root examples/rtl_schematic_dsp_complex --top DSP_stream \
  --file DSP_stream.sv --file DSP_frontend.sv --file DSP_fir.sv \
  --file DSP_mul_lane.sv --file DSP_saturate.sv
```

Open <http://127.0.0.1:8765>. View the top's port wires, right-click
`u_filter` for **View SystemVerilog**, double-click to navigate into its FIR,
select any routed wire segment or expand **6 generated multiplier lanes**.
Open `u_mult` to inspect the explicit AST multiplier and sequential boundary.
Pin a signal using Ctrl/Cmd or the context menu and drill into an instance:
tracking only succeeds for an AST-proven whole-port connection.

## Offline interactive mockup (not compiler output)

`rtl_viewer_mockup.html` is a standalone UI **demonstrator**, produced by:

```bash
python scripts/build_rtl_viewer_mockup.py --complex
```

`DSP_stream.mock_ast.json` is **hand-authored test data** for offline UI work.
It is not generated by Slang and must never be considered proof that this RTL
compiled. Sliced bus connections are deliberately omitted from the fixture:
`coeff_i[tap*WIDTH +: WIDTH]` is not shown as a resolved whole-port mapping.

The CI integration test `tests/rtl_viewer/test_complex_dsp_slang.py` calls the
real compiler and is skipped, not counted PASS, when Slang is unavailable.
